# YC Video Narration — Sunday Relay (~80 seconds)

> Founder voice, plain language. On-screen: `npm run relay:yc`. The
> demonstration is Relay's real orchestration engine running deterministic
> simulated agents — say so, and never claim live provider integration is
> finished.

**0–10 s** (banner + objective on screen)
"If you build with AI agents today, you're the relay — copying prompts,
context, and results between Claude Code, Codex, and whatever else you use.
Every handoff loses context. Nobody checks anyone's work."

**10–25 s** (PROJECT BRAIN + PLAN + TASK OWNER)
"This is Sunday Relay. Relay keeps one Project Brain — the objective, the
architecture, the safety rules — owned by your project, not by any one AI
vendor. It plans the work, and assigns one owner per task."

**25–45 s** (HANDOFF + ATTEMPT 1 + VERIFICATION FAIL)
"Instead of forwarding a chat transcript, Relay compiles a responsibility
contract: exactly what this agent may touch, what's protected, and what
proof is required. The coding agent reports success — but Relay doesn't
trust self-reported success. It runs its own checks… and one fails: the
anonymous spend control isn't proven."

**45–65 s** (REVIEW + REPAIR + RE-VERIFICATION)
"An independent reviewer confirms the problem. Relay authorizes exactly one
bounded repair — same agent, same session, same scope, nothing widened —
then re-verifies everything and sends it back for independent review."

**Supporting beat — Manual Task (one sentence, placed wherever it fits;
Prompt 6.1)**
"When Relay reaches something only a person should do, it stops and gives
the user a few simple steps instead of guessing or bypassing security."

**65–80 s** (FINAL AUDIT + RELAY COMPLETE)
"Only now — evidence verified, review approved, every claim promoted with
proof — does Relay mark the task complete, with a full audit trail.
What you just watched is our real orchestration engine running simulated
agents; the live Claude Code and Codex connectors plug into these same
contracts next. Sunday Relay: pass the work, keep the context."
