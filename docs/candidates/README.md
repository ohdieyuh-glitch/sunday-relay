# Julius mission candidates

A **candidate** is the workspace diff a paid Julius mission produced inside its
disposable sandbox. Julius never writes trusted main; this directory is where a
candidate is preserved after the run's evidence artifact expires.

A candidate here is NOT merged, NOT endorsed, and NOT scheduled to land.
Landing one is a separate human decision, taken against the mission's own
record in `docs/JULIUS_PAID_RUN_<run id>_*.md`.
