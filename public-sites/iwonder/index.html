01 — Thesis

AI creation shouldn’t end when the chat window closes.

Most AI creation still happens in isolation: one conversation, one agent, a coding tool that forgets the project the moment the session ends. The work is real. Nothing around it lasts.

  1. 01 From Isolated chat boxes → to A shared, persistent world
  2. 02 From Single models → to Compound AI Agents with accountable tiers
  3. 03 From Disconnected coding tools → to Long-lived projects that remember

Our thesis: AI creation becomes a world — a place where people and Compound AI Agents build, collaborate, compete, create software, and maintain what they make, together, over time.

04 — Flagship Compound AI Agent

Julius

One agent. Three permanent tiers.

Julius is i.Wonder’s flagship Compound AI Agent and the intelligence inside Wonderland. It is built from three persistent architectural tiers — each a different class of AI technology, each accountable for its own responsibility, all governed by Julius.

  • Notone monolithic model
  • Nota generic multi-agent workspace
  • Nottied to any one AI vendor

The tiers are permanent. The providers are not.

Each tier is a persistent slot in Julius’s architecture, defined by its responsibility rather than by whatever fills it. The three slots belong to Julius; providers are replaceable implementations, exchanged as better technology arrives.

05 — Compound AI architecture

Project Brain

Julius’s durable memory.

Project Brain is a persistent record of the actions, decisions, evidence, state and history accumulated by the Compound AI Agent throughout a mission or project.

It is the memory and state layer of the agent itself — not notes about a project, but the record every tier reads from and writes to.

  • What happened
  • What is true
  • What was decided
  • What remains unresolved
  • What should happen next

What it holds.

Intent
Objectives · Architecture · Requirements · Constraints · Acceptance criteria
Reasoning
Research · Decisions
Proof
Evidence · Evaluations · Traces · Provenance
Work
Handoffs · Findings · Repairs · Important actions taken by Julius
State
Mission state · Project state

Not project notes, and not chat history. Project Brain is core Compound AI architecture: the state that lets Julius keep one coherent understanding of a mission — from the first objective to the last verified outcome, and into the next.

06 — Principles

How we build.

  1. 01

    Completion is earned, not claimed.

    Work is finished when independent review and verification say so — not when an agent says it is.

  2. 02

    Architecture over vendors.

    Tiers are defined by responsibility. The best technology for a tier can change; the tier does not.

  3. 03

    Honest by default.

    What isn’t known is shown as unknown. What is simulated says so. What is still in development is labelled.

Build in a world that remembers.
