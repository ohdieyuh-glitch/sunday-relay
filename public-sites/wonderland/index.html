01 — The world

Not a chat window. A place.

Wonderland is a persistent, open world built for AI creation. Your projects, your agents and your progress live inside it — and they stay.

  • Create

    AI-powered creation

    Shape ideas into worlds, objects and experiences, with AI as a creative collaborator.

  • Build

    Real software

    Software development by Compound AI Agents inside the world — verified before it’s called done.

  • Collaborate

    People and agents, together

    One shared context, clear roles and a shared memory for everyone on the project.

  • Compete

    Stakes and momentum

    Challenges, social systems and game-like progression that keep long-lived creation moving.

02 — Persistent

The world remembers.

Sessions end. Wonderland doesn’t. Projects, decisions and progress persist, so long-lived work keeps growing — with every participant, human or agent, working from the same memory.

  1. Projects

    Stay where you left them, session after session.

  2. Project Brain

    Durable context — objective, decisions, constraints, findings and evidence — shared by every role.

  3. Agents

    Keep their configuration and identity, so the agent you return to is the one you built.

03 — Powered by Julius

Meet Julius.

Julius is i.Wonder’s primary Compound AI Agent and the intelligence behind creation in Wonderland. Not one model answering prompts — persistent, provider-independent roles working under a single authority that owns the mission from brief to finish.

  1. 01

    Prompt Architect

    Turns intent into a precise, buildable brief, grounded in everything the project already knows.

  2. 02

    Coding Agent

    Does the work — real code, real changes, real checks — inside the permissions it was given.

  3. 03

    Independent Reviewer

    Examines the result apart from the agent that produced it, and approves only what the evidence supports.

Julius holds authority over

  • Mission authority
  • Orchestration
  • Dependencies
  • Permissions
  • Budgets
  • Project Brain & context
  • Synthesis
  • Conflict resolution
  • Verification
  • Termination

When justified

Multi-Agent Swarm

For work that genuinely benefits from it, Julius opens a temporary swarm of specialized Compound AI Agent clones — bounded, budgeted, and resolved back into one verified result.

04 — How work gets done

Completion is earned, not claimed.

Every mission walks the same loop. An agent saying it’s finished is not the end of one.

  1. 01

    Brief

    Prompt Architect

    Intent becomes a precise, buildable brief.

  2. 02

    Build

    Coding Agent

    The work gets done, with real changes and real checks.

  3. 03

    Review

    Independent Reviewer

    The result is examined apart from the agent that made it.

  4. 04

    Repair

    Coding Agent

    Findings go back to the role that owns them.

  5. 05

    Verify

    Julius

    Evidence is checked against the brief.

  6. 06

    Complete

    Julius

    Only when the evidence holds.

05 — C.A.R.D.

Configure once. Build everywhere.

Every Compound AI Agent in Wonderland is described by one C.A.R.D. — a single, legible configuration. Configure it once; every mission reads the same one, and it changes only when you edit it.

06 — The Relay Dog

Every agent has a face.

In Wonderland, your Compound AI Agent appears as a Relay Dog — a voxel companion that lives in the world and carries your agent’s identity, so the agent is present rather than hidden behind a text box.

  1. Skins

    Skins transform the Dog. The silhouette always stays.

  2. Breath

    It breathes — ambient life, never a fake status light.

  3. Attention

    It looks where you look. On a desktop, move your cursor.
